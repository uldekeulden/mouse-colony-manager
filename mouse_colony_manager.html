Animal protocol

Rooms

Configured housing rules:
Per-room cage capacity and per-cage sex limits are set in Rooms above; the example ships with Room A (max 4 adult males / 5 adult females per cage) and Room B (max 5 adults per cage).
Unweaned pups remain represented by their litter record and are not counted as adult cage occupants until weaning. After a litter is recorded, the system alerts you if the breeding male is still in that cage.

Strains & default genotype

A line kept homozygous carries the same genotype in every animal, so there is no need to retype it per mouse. Set the default here and leave the per-mouse genotype blank: it is inherited and shown with a from strain marker. Record a per-mouse genotype only when that animal actually differs, for example a Het littermate from a segregating cross.

Shareable colony report

A read-only, good-looking snapshot of the dashboard. Every style is written inline and every colour is a literal hex value, with no script and no external requests, so it renders the same offline as online.

To send it, pick whichever fits:
1. Attach the file. The recipient clicks it and it opens in their browser looking exactly as intended. This is the reliable route.
2. Paste it into the email body. Open the file in Chrome or Safari, select all, copy, then paste into Gmail, Outlook or Apple Mail. The inlined styles travel with the paste, so colours and layout survive in the message preview.

What will not survive: the Nunito typeface is not embedded, so a reader without it installed sees Avenir Next or Helvetica instead. Outlook on Windows uses the Word rendering engine and will square off the rounded corners. Both degrade to something still perfectly readable.

How saving works

Source of truth: the current colony data is embedded directly inside this working HTML. Chrome localStorage, IndexedDB, cookies, and cache are not used. After editing, save a new working HTML and replace the copy in your locally synced synced cloud folder. The next time you open that file, the saved data loads automatically—even after Chrome has been completely reset.
The two save buttons live in the bar at the top of every page. in desktop Chrome/Edge, “Save / Replace Working HTML…” opens a normal file-save dialog. Choose your synced cloud Mouse Colony folder and overwrite the working HTML. If the browser does not support that picker, the button falls back to a normal download.

Backup, archive & sharing

JSON is the recovery backup. Excel creates a real multi-sheet .xlsx workbook with Mice, Genotypes, Cages, Breeding, Litters, and Events. Snapshot HTML is a static read-only file intended for synced cloud sharing; it contains no browser database and does not need your working JSON.
